# Code of Conduct

This project is a place for respectful technical collaboration.

Participants are expected to:

- discuss ideas and code without personal attacks or harassment;
- assume good faith while remaining specific about technical concerns;
- respect different backgrounds, experience levels, and communication styles;
- avoid publishing another person's private information; and
- accept maintainer decisions about project scope and moderation.

Unacceptable behavior may be removed, and repeated or serious violations may result in temporary
or permanent exclusion from project spaces.

To report conduct that should not be handled publicly, email lim@limsumin.com. Reports will be
reviewed privately and handled within a reasonable time, as fairly as practical.
